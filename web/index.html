mAP 用低置信度预测绘制整条 PR 曲线；表中的 Precision / Recall 固定在 0.25 阈值，因此若模型没有预测超过该阈值的框，P/R 会是 0。mAP 越高通常表示检测质量越好；延迟越低表示单张处理越快。当前 test split 曾用于探索性实验，正式报告应另用未参与调参的独立测试集。模型结构或训练设置不同时，这是系统级对比，不能单独证明某一个改进方法导致了性能变化。

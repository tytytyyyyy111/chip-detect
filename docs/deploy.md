# 部署说明

## 一、端口规划

| 端口 | 服务 | 协议 |
|---|---|---|
| 8012 | 检测 | HTTPS + mTLS |
| 8013 | 预处理 | HTTPS + mTLS |
| 8014 | 网页与业务接口 | HTTP |
| 8015 | 报告 | HTTPS + mTLS |
| 8016 | 回流 | HTTPS + mTLS |
| 8017 | 主控 AIP | HTTPS + mTLS |

对外映射示例：8443~8447 分别对应上游 8013 / 8012 / 8015 / 8016 / 8017。

## 二、启动顺序

1. 确认证书与信任库就位
2. 设置环境变量（见 README）
3. 启动四个能力型智能体
4. 启动主控
5. 启动网页服务
6. 启动日志转发与心跳守护

## 三、守护与自恢复

推荐用系统计划任务而非手工启动：

- 手工在当前会话启动的子进程，会话结束即被回收
- 计划任务可设为开机启动并以系统身份运行，不依赖登录会话

任务内容：每 5 分钟检查各端口与关键进程，缺失则拉起。

注意：任务参数中的中文路径可能被系统按 ANSI 编码存储而损坏，建议为工作目录建立一个 ASCII 路径的目录联接，任务指向联接路径。

## 四、对外暴露

若通过内网穿透对外提供服务：

1. 穿透服务端（frps）需配置为开机自启，否则重启后全线不可达
2. 客户端（frpc）应设置登录失败不退出，避免服务端未就绪时客户端直接终止
3. 云主机安全组与系统防火墙是两层，都要放行

## 五、常见故障排查

| 现象 | 排查顺序 |
|---|---|
| 平台显示调用失败 | 1. 公网端口是否可连 2. 握手是否成功 3. 是否被 token 网关拦截 |
| 发现服务搜不到 | 1. 心跳是否在写 2. 是否按技能名检索 3. 智能体是否为在线状态 |
| 服务启动后立即退出 | 1. 端口是否被占用 2. 证书是否可读 3. 环境变量是否缺失 |
| 追问后任务不继续 | on_continue 是否实现了业务逻辑 |

## 六、安全清单

- [ ] 私钥权限限制为服务账号可读
- [ ] 网页入口启用访问令牌
- [ ] AIP 端点仅走 mTLS，不暴露明文
- [ ] 管理端口（SSH / RDP）限制来源 IP
- [ ] 日志中不记录令牌与私钥
- [ ] 定期轮换访问令牌
